# Cutroom design

The video is the work surface: a charcoal screening room with a quiet, warm-white review notebook alongside it. Muted blue marks the playhead and active cut; green means keep, amber means change. No marketing hero or dashboard metrics.

Palette: screening room #1f2227, workspace #282c32, notebook #f5f5f2, ink #242933, focus blue #5879cb, keep green #28775b. Type: Avenir Next on Mac, system sans-serif elsewhere. Tabular numerals only where timing needs alignment.

Desktop: compact project rail | large player above a horizontal strip of real cut thumbnails | a persistent comment notebook. All headings left aligned. The timeline carries clickable feedback markers. On smaller screens, the notebook moves below playback and the project rail collapses.

Review against brief: the main distinction is the contrasting review notebook beside the actual footage, not generic dashboard cards. The thumbnail strip uses the real six cuts and keeps their names visible. Comments start empty rather than inventing feedback. Keep familiar playback controls and visible saves.
